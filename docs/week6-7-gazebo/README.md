# Weeks 6-7: Robot Simulation with Gazebo

## Overview

This module covers robot simulation with Gazebo for humanoid robotics applications. The content is structured across two weeks focusing on simulation environment setup, robot description formats, and physics/sensor simulation.

## Learning Objectives

By the end of this module, readers will understand:
- Gazebo simulation environment setup for humanoid robots
- URDF and SDF robot description formats for simulation
- Physics simulation including gravity, collisions, and material properties
- Sensor simulation for various robot sensors (LiDAR, cameras, IMUs)

## Module Structure

- **Week 6**: Gazebo simulation environment setup and URDF/SDF robot description formats
- **Week 7**: Physics simulation and sensor simulation

## Prerequisites

- Intermediate Python knowledge (classes, async, decorators)
- Basic Linux command line experience
- Foundational AI concepts (understanding of LLMs, VSLAM)
