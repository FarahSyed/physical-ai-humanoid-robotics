# Quickstart Guide: Weeks 6-7: Robot Simulation with Gazebo

## Overview
This guide provides a quick introduction to Weeks 6-7: Robot Simulation with Gazebo for humanoid robotics. The module emphasizes theoretical understanding of Gazebo simulation environment setup, URDF and SDF robot description formats, and physics/sensor simulation with minimal code examples for reference.

## Prerequisites
- Intermediate Python knowledge (classes, async, decorators)
- Basic Linux command line experience
- Foundational AI concepts (understanding of LLMs, VSLAM)
- Completion of Weeks 1-5 ROS 2 fundamentals

## Getting Started

### 1. Environment Setup
The module content assumes an Ubuntu 22.04 LTS environment with Python 3.10 and Gazebo Fortress.

```bash
# Install Gazebo Fortress
sudo apt update
sudo apt install gazebo libgazebo-dev
# Install ROS 2 Jazzy Gazebo packages
sudo apt install ros-jazzy-gazebo-ros-pkgs ros-jazzy-gazebo-ros2-control
```
