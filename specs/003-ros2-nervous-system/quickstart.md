# Quickstart Guide: Weeks 3-5: ROS 2 Fundamentals

## Overview
This guide provides a quick introduction to Weeks 3-5: ROS 2 Fundamentals for humanoid robotics. The module emphasizes theoretical understanding of ROS 2 architecture, building packages with Python, and launch files and parameter management with minimal code examples for reference.

## Prerequisites
- Intermediate Python knowledge (classes, async, decorators)
- Basic Linux command line experience
- Foundational AI concepts (understanding of LLMs, VSLAM)
- No prior ROS experience required

## Getting Started

### 1. Environment Setup
The module content assumes an Ubuntu 22.04 LTS environment with Python 3.10 and ROS 2 Jazzy Jalisco.

```bash
# Install ROS 2 Jazzy (LTS) on Ubuntu 22.04
sudo apt update
sudo apt install software-properties-common
sudo add-apt-repository universe
sudo apt update
sudo apt install ros-jazzy-desktop
sudo apt install ros-dev-tools
```
